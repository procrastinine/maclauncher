The idea behind MacLauncher is simple: these are *your* games, on *your* disk, and the launcher's job is to help you do whatever you want with them. So beyond "import and play", there's a whole toolbox for people who like to look under the hood.

## The philosophy

- **Local first.** MacLauncher works with your local files. Original game files are never modified; generated files, caches, private copies and exports live in MacLauncher's own storage, and **Forget** cleans them up.
- **Control everything.** Runtimes expose their settings, you can pass any launch flags you like, and every game has its own overrides.
- **Versions for everything.** Runtimes, tools, store downloads and accounts can all be managed by version, so you can always pick exactly what you use. Sensible defaults are there when you don't care.
- **No surprise network traffic.** MacLauncher never phones home or checks for things in the background. Every network request comes from something you did, like refreshing a version list, installing something, or browsing a store. Every game also has a **Network access** switch that can cut it off from the Internet.

## What's in the box

### [Stores and downloads](/maclauncher/tools/stores-and-downloads/)

Find the games already installed from [Steam](https://store.steampowered.com/), [Epic](https://store.epicgames.com/), [GOG](https://www.gog.com/) and [itch.io](https://itch.io/), and download games you own straight from those stores: any platform, any version you can get at. That includes the Windows build of a Steam game on a Mac, or an older build by its manifest ID. Android apps come from [Google Play](https://play.google.com/store/games), [F-Droid](https://f-droid.org/) and [IzzyOnDroid](https://apt.izzysoft.de/fdroid/).

### [Saves and cheats](/maclauncher/tools/saves-and-cheats/)

Find where a game keeps its saves, take snapshots before you experiment, restore them, and edit [RPG Maker](https://www.rpgmakerweb.com/) MV/MZ saves field by field. Cheats are built in for RPG Maker and [Ren'Py](https://www.renpy.org/) games.

### [Decompilers and extractors](/maclauncher/tools/decompilers-and-extractors/)

Unpack archives, decrypt assets and decompile scripts and code for most engines MacLauncher supports, from Ren'Py and RPG Maker to [Unity](https://unity.com/), [GameMaker](https://gamemaker.io/), Java, Flash and Android. The tools download on demand.

### [Versions and settings](/maclauncher/tools/versions-and-settings/)

Install and switch between runtime versions, set defaults and per-game overrides, add launch arguments, save `.command` launchers, and run games from the command line.
