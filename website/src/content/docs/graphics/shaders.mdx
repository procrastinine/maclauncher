Shaders are small GPU programs that transform an image. The communities around [ReShade](https://reshade.me/), [RetroArch](https://www.retroarch.com/), [mpv](https://mpv.io/), [Magpie](https://github.com/Blinue/Magpie) and other projects have written thousands of them, from CRT simulations and anime upscalers to film grades, bloom and ambient occlusion. MacLauncher runs shaders from all of these projects on macOS, side by side in the same chain, so shaders you already use elsewhere can often be used here too.

## Formats

MacLauncher accepts shaders in these formats:

| Format | Files | Where it comes from |
| --- | --- | --- |
| ReShade FX | `.fx` | ReShade's large library of post-processing effects for PC games. Techniques, includes, lookup textures and parameters all work. |
| [RetroArch Slang](https://github.com/libretro/slang-shaders) | `.slangp`, `.slang` | RetroArch's shader presets, run through [librashader](https://github.com/SnowflakePowered/librashader) on [Metal](https://developer.apple.com/metal/). Multi-pass presets keep their scaling and textures. |
| mpv / [libplacebo](https://libplacebo.org/) | `.glsl`, `.hook` | Video-player shaders: upscalers like [Anime4K](https://github.com/bloc97/Anime4K) and FSRCNNX, chroma reconstruction, debanding, grain. |
| LUT | `.cube` | Color grades from photo and video editors, as 1D, 3D or combined tables. |
| [ISF](https://isf.video/) | `.fs`, `.isf` | Interactive Shader Format effects from the VJ and video world. |
| MagpieFX | `.hlsl` | The effect format of Magpie, the Windows window upscaler, including its neural upscalers. |

## The shader library

All shaders live in one shared library: the effects included with MacLauncher, the ones from installed collections, and the files you import. You can open it with **Manage filters…** in the inspector, which shows the library in **Runtimes → Graphics → Shaders**.

To add your own shader, use **Import filter…**, drop the file onto MacLauncher, or open it from Finder. The library records where the file lives and never copies or changes it. Includes, preset passes and textures are also read from their places next to the shader, so a shader folder works as it is. Imported shaders appear in the matching menus immediately, and an entry can be renamed for display without changing which file it uses.

For one-off use, **Custom shader…** on a chain row points that row directly at a file.

## Parameters

Most shaders expose settings, which **Shader parameters…** on a row lists with their original names, defaults and ranges. Changes apply live, and changing a compile-time setting recompiles the shader in the background while the game keeps running. Because each row keeps its own values, the same shader can appear twice with different settings.

Shaders that read the game's depth also get **Depth input** settings, for games that store depth reversed, logarithmically or with an unusual far plane. These settings are shared by all of a game's depth shaders.

## Collections

Collections are curated sets of shaders from upstream projects. They are managed in **Runtimes → Graphics → Shaders → Collections**, where **Refresh** lists a collection's versions and **Install** downloads one from the original source. Each installed collection records its exact source version and keeps its license notices.

| Collection | What's inside |
| --- | --- |
| Anime4K | Anime upscaling, restoration, denoising and line thinning. |
| [ArtCNN](https://github.com/Artoriuz/ArtCNN) | Neural upscalers and restoration for anime and art. |
| [CuNNy](https://github.com/funnyplanter/CuNNy) | Learned upscalers for text, line art and visual novels. |

| [Chroma from Luma](https://github.com/Artoriuz/glsl-chroma-from-luma-prediction) | Rebuilds color detail from brightness detail. |
| MagpieFX | Magpie's filters and scaling shaders, including its neural networks. |
| libretro Slang | Pixel-art scalers such as [xBRZ](https://github.com/libretro/slang-shaders/tree/master/edge-smoothing/xbrz) and [SABR](https://github.com/libretro/slang-shaders/tree/master/edge-smoothing/sabr), dedithering, restoration filters and CRT halation. |

| [prod80](https://github.com/prod80/prod80-ReShade-Repository) | Film-style grading, curves, LUTs, exposure and grain. |
| [CShade](https://github.com/papadanku/CShade) | Image-based optical flow, motion blur, auto exposure and filters. |
| [FXShaders](https://github.com/luluco250/FXShaders) | NeoBloom, ArcaneBloom, grading and lens effects. |
| [NiceGuy shaders](https://github.com/mj-ehsan/NiceGuy-Shaders) | Screen-space lighting, reflections and depth fog. |
| [Visibility bitmask lighting](https://github.com/cdrinmatane/SSRT3) | SSRT3 indirect lighting from real depth, normals and lighting. |
| [AstrayFX](https://github.com/BlueSkyDefender/AstrayFX) | RadiantGI indirect lighting, GloomAO ambient occlusion, anti-aliasing, Smart Sharp and Clarity sharpening, bloom, lens flare and image trails. | [OtisFX](https://github.com/FransBouma/OtisFX) | Cinematic depth of field, adaptive and height fog, depth haze, MultiLUT and PandaFX grading, and golden-ratio composition guides. |

Whether a shader comes from a collection or from your own files, MacLauncher places it in the chain by what it declares about its output size and inputs, whatever its name. A shader that always doubles its input is an Upscale, one that keeps the size is an Image filter, and one that needs depth is marked as such and runs only in games that provide depth.

The [shader library section](https://github.com/procrastinine/maclauncher/blob/master/docs/graphics/README.md#shader-library) of MacLauncher's graphics guide has the complete details for each format and [collection](https://github.com/procrastinine/maclauncher/blob/master/docs/graphics/README.md#collections), and the [shader integration reference](https://github.com/procrastinine/maclauncher/blob/master/docs/graphics/SHADERS_AND_MEDIA.md) describes how shaders are sized and which inputs they receive.
