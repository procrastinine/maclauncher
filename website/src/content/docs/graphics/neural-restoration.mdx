Ordinary upscalers follow fixed rules about how to fill in new pixels. Neural models have *learned* what images tend to look like: how a line in an anime drawing should continue, what grass looks like up close, what's noise and what's detail. Given a small or damaged image, they redraw it with that knowledge.

MacLauncher runs these models on your Mac's GPU through [MLX](https://github.com/ml-explore/mlx) and [Metal](https://developer.apple.com/metal/), inside the same graphics chain as everything else. They need an Apple Silicon Mac with macOS 14 or later. Intel games running under [Rosetta](https://support.apple.com/en-us/102527) or [CrossOver](https://www.codeweavers.com/crossover/) can use them too: a small Apple Silicon helper runs the model while the game runs translated.

## The models

| Model | What it does | Output size |
| --- | --- | --- |
| <span id="real-esrgan"></span>Real-ESRGAN | Anime and General upscalers. General comes with a paired denoising model, and a **Denoise strength** control blends between them. | 4× |
| <span id="real-cugan"></span>[Real-CUGAN](https://github.com/bilibili/ailab/tree/main/Real-CUGAN) | Upscaler trained on anime, in Conservative, No denoising and Denoise variants. | 2×, 3× or 4× |
| <span id="rtx-video-super-resolution"></span>RTX Video Super Resolution | NVIDIA's video upscaler, through [MLX-DLSS](https://github.com/iamwavecut/MLX-DLSS). | 2× |
| <span id="dlss-neural-rendering"></span>DLSS neural rendering | The DLSS 5 neural rendering model through MLX-DLSS. It redraws the image toward a photoreal look, blended in with **Intensity**, and can keep image history with **Temporal reconstruction**. | Same size |
| <span id="dlss-sr-image"></span>DLSS SR (image) | DLSS super resolution working from a sequence of finished images. | 2× |
| <span id="nafnet"></span>NAFNet | SIDD (denoising) and GoPro (deblurring) restoration models. | Same size |

The neural family also includes [RIFE](https://github.com/hzwer/Practical-RIFE) and MLX interpolation for [frame generation](/maclauncher/graphics/frame-generation/), and [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2), which guesses depth from a flat image for the [estimated depth fog](/maclauncher/graphics/color-and-light/) effect.

Real-ESRGAN and NAFNet build on the existing [Real-ESRGAN MLX](https://github.com/xocialize/mlx-realesrgan-swift) and [NAFNet MLX](https://github.com/xocialize/mlx-nafnet-swift) ports; Real-CUGAN runs its original models on MLX.

## Getting models

Models aren't bundled with the app. In **Runtimes → Graphics → Neural models** you can **Install** any of the supported downloads after agreeing to it, or import a model you already have. Once installed, a model works offline and is shared by every game.

Each neural row in the chain has a **Model** menu. **Automatic** picks a sensible installed model for that operation, and you can choose a specific one per row or set a default per operation. If a row's model is missing, the rest of the chain keeps running and the row says **Model needed**.

## Keeping it fast

Neural models are heavy, and their cost grows with the number of pixels they process. The usual trick is to give them a smaller image: a **Downsample** row before the model (or a lower **Game resolution**), then a fast upscaler such as [MetalFX](https://developer.apple.com/documentation/metalfx) afterward to fill the window. [Building a chain](/maclauncher/graphics/composing-effects/) shows how that looks, and frame generation can smooth things out if the model still can't keep up with the game.

The [neural models section](https://github.com/procrastinine/maclauncher/blob/master/docs/GRAPHICS.md#neural-models) of the graphics guide and the [restoration reference](https://github.com/procrastinine/maclauncher/blob/master/docs/NEURAL_RESTORATION.md) list every download, import format and setting.
