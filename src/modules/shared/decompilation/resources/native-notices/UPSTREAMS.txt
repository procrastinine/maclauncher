Native inspection components from the upstream Cutter macOS distribution:

Rizin — LGPL-3.0-or-later
https://github.com/rizinorg/rizin

rz-ghidra — LGPL-3.0-or-later
https://github.com/rizinorg/rz-ghidra

Ghidra decompiler and Sleigh language definitions — Apache-2.0
https://github.com/NationalSecurityAgency/ghidra

The original release archive, exact Cutter source revision and SHA-256 are
recorded in runtime.json. CLI files are copied from that distribution; local
ad-hoc signatures permit loading the selected private native library directory.
Qt, the Cutter GUI and Python are not part of this CLI installation.
