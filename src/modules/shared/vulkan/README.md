# Native Vulkan libraries

MoltenVK and KosmicKrisp appear under Graphics in Runtimes. Installation uses versioned publisher binaries, including their license notices. Settings reads available versions without downloading files. Android selects a native implementation per game; Automatic uses an installed MoltenVK version, then an installed KosmicKrisp version, then the included KosmicKrisp adaptation when compatible. All use the host process architecture. The Windows Wine runtime keeps its own graphics package and architecture choices.

MoltenVK loads its dynamic library directly. KosmicKrisp uses the Khronos Vulkan loader and a private ICD manifest naming the selected driver. Managed driver and loader binaries have system-only native dependencies. The included adaptation retains its compiler and compression dependencies in the same sealed component, with relative library references. Each component is checked against the current CPU architecture and macOS version. Game sandboxes grant read and executable mapping access to those selected library files, without granting their parent runtime directories.

MoltenVK downloads come from KhronosGroup releases. KosmicKrisp comes from the versioned LWJGL native distribution; its Mesa commit is recorded in the catalog. The loader comes from Homebrew's published Vulkan-Loader binary bottle and retains its original license. Versioned artifacts have SHA-256 identities, and installation retains only the native libraries and notices.

The optional **KosmicKrisp · GLES 3.2 (included)** selection contains a MacLauncher adaptation of Mesa. Mesa Poly supplies geometry shaders, transform feedback and generated-primitive queries through the original KosmicKrisp shader compiler and GPU command encoders. ANGLE's Vulkan renderer uses those features for OpenGL ES 3.2, including tessellation, geometry and compute shaders. The included component requires Apple Silicon and macOS 27.0; dependency identities and license notices accompany the native files. Source and owned adaptations are available in the tagged Builds repository. Stock KosmicKrisp versions retain their publisher identities and feature sets. Android continues to use ANGLE Metal by default; ANGLE Vulkan uses the selected Vulkan component.

`native/kosmickrisp-source.json` pins the original Mesa source. `native/kosmickrisp-source.mjs` applies the owned adaptation to a separate source projection, and `native/kosmickrisp-build.mjs` builds only KosmicKrisp and its shared compiler. The recipe accepts explicit source, Meson, Ninja, LLVM, Vulkan loader and license-file paths, reuses unchanged source and compiler outputs, and publishes the component's actual native dependency closure. The `--resource-root` option stages the completed component and updates this module's supplemental declaration.

Android maps `VK_KHR_android_surface` to the selected driver's `VK_EXT_metal_surface`. The driver owns Vulkan queues, images, swapchains and synchronization. Its Metal carrier layer registers with the common graphics presenter; each completed producer frame follows the same Android overlay and graphics pipeline as EGL and Canvas. Native-window resize updates the carrier's source extent independently of the display extent. Presentation borrows GPU resources until command completion and performs no per-frame CPU image copy.
