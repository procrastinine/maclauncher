# RPG Maker 2000/2003

RPG Maker 2000 and 2003 games store their database and maps in LCF files. MacLauncher plays them with [EasyRPG Player](https://easyrpg.org/player/), an open-source reimplementation of the RPG Maker 2000/2003 engine, and exports their project data as JSON and text. RPG Maker XP, VX, VX Ace, MV and MZ are separate game types with their own runtimes.

## Detection

Import accepts the game folder, `RPG_RT.exe`, `RPG_RT.ldb` or `RPG_RT.lmt`. MacLauncher identifies the database (`RPG_RT.ldb`) and the map tree (`RPG_RT.lmt`) by their LCF signatures. The inspector's details show the game format, the maps, the declared text encoding and any DynRPG plug-ins.

The game's own folder supplies its graphics, audio and other required assets. Games that rely on the RPG Maker Run Time Package (RTP) can use installed RTP assets through **RTP folders**.

## Runtimes

| Runtime | Delivery |
| --- | --- |
| EasyRPG Player (default) | Official Mac release from **Runtimes → EasyRPG Player** |
| CrossOver, Sikarugir (Wine) | Windows runtimes for the original `RPG_RT.exe` |

### EasyRPG Player versions

**Runtimes → EasyRPG Player** lists the official releases from 0.8 onward from the publisher's [versioned Mac downloads](https://easyrpg.org/downloads/player/), which hold one folder per release. A release's download is the publisher's usual Mac archive or, when the release renames or repackages it, the Mac download in that release's folder; per-processor downloads are listed separately. Release records keep the publisher URL of each download. Before any list has been read, Play reads the release list with consent and installs the newest release. The publisher lists no digest, so installation records a local SHA-256 for later integrity checks.

The selected Mac app supplies its executables and native dependencies. Intel-only releases run under Rosetta on Apple silicon, which MacLauncher determines from the executable's CPU information.

### Settings

Settings are available globally and for each game:

| Setting | Effect |
| --- | --- |
| **Fullscreen** | Starts in fullscreen. |
| **Scaling** | Integer (default), nearest or bilinear scaling. |
| **Engine mode** | The original engine edition. Automatic detection is the default; an explicit edition helps games whose version is detected incorrectly. |
| **Text encoding** | Empty for automatic detection, or a code page such as 932 (Japanese) or 1252 (Western European). |
| **Translation language** | Selects a matching `language` folder supplied with the game. |
| **RTP folders** | Absolute paths to installed RPG Maker 2000/2003 RTP assets. |
| **MIDI soundfont** | An absolute path to an SF2 soundfont. Without the game's or a selected soundfont, MIDI plays through EasyRPG's built-in FM synthesizer. |
| **Disable audio** | Turns audio off. |
| **Show frame rate** | Displays the frame rate. |
| **Game arguments** | Additional EasyRPG options, one argument per line. |

An explicit engine mode or text encoding overrides automatic detection.

## Saves

EasyRPG opens the original project folder and uses it as the working directory. Saves stay in that project, as the engine does by default. An explicit save-folder override passes `--save-path`; Play does not copy existing saves or create a private project view. New games use EasyRPG's own configuration and log defaults. An explicit configuration-path argument takes precedence; shared Player preferences are not assigned a new identity for each game. Save snapshots, import and export, and revealing the save folder work with `.lsd` files.

## Tools

The inspector's **Project data** group has **Export project JSON**, **Export game text** and **Reveal export**, and **Inspect project** is under **Advanced**. These read-only tools decode the database, the map tree and the map files with the [rpgrt 0.2.0](https://github.com/johannschopplich/rpgrt) library, which is included with MacLauncher.

- JSON exports contain the structured project data: database, map tree, maps and events.
- Text exports contain the dialogue, names and other strings, each with the address of its source field, for translation.

Event commands stay engine records; they are not converted to Ruby or JavaScript. Exports are written to `games/<gameId>/modules/easyrpg/exports/`, and the engine edition and text encoding from the runtime settings apply when they are set. Exports are limited to 4,096 files, 16 MB per input file, 128 MB of input in total and 256 MB of output.
