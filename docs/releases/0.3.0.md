MacLauncher 0.3.0 is a major overhaul, with a redesigned library, a new logo, many more native game runtimes, and more tools for working with game files and saves.

- **More game engines:** GameMaker through the official runner, Butterscotch and a macOS port of OpenGMK; Unity Mono; XNA/FNA; LÖVE; Flash through Adobe Flash Player or Ruffle; Java; Infinity Engine through GemRB; MUGEN through Ikemen GO; and Haxe through HashLink.
- **More visual novels:** KiriKiri/KAG through krkrsdl2 and KAG3, MAGES through Impacto, AI5WIN through AI5-SDL2, AliceSoft through System3/xsystem35/xsystem4, Siglus and RealLive through siglus_rs, RealLive through RLVM, Nitroplus through NPengine, Minori through ReMinori, and VNDS through VNDS-LOVE. NScripter also gains a macOS port of ONScripter-EN alongside Onscripter-Yuri.
- **Import and Play:** automatic game detection and preparation, with permission requested before downloading a needed runtime. Python and extraction helpers are included; no separate installation is needed for them.
- **Runtime choices:** select compatible runtime versions per game and manage downloads in the Runtimes window. RealLive games can choose between siglus_rs and RLVM.
- **Game tools:** expanded extraction, decompilation, cheats, save editing and offline Steam API support. BGI and CatSystem2 gain detection and extraction/decompilation tools; they are not yet supported for play.
- **Mac interface:** a redesigned game inspector and separate Settings, Runtimes and Credits windows, with native menus and keyboard shortcuts.

Existing RPGMaker, web-game, Ren'Py and Godot support remains included. Network access stays tied to explicit runtime and tool download actions.
