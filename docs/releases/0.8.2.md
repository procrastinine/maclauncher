MacLauncher 0.8.2 gathers the Wine sources under one runtime choice, shows Live2D according to the Ren'Py runtime, and installs Zstandard-compressed runtime archives on every Mac.

- The game inspector and Settings offer one **Wine** runtime, and a **Wine** menu chooses CrossOver, Sikarugir, WineCX, Highball Wine or MetalSharp Wine. Settings has one **Wine** tab for the Wine settings and a **Default Wine** choice.
- With the Ren'Py SDK runtime, the inspector shows the Live2D library of the selected SDK version, which Runtimes manages. The per-game Live2D tools appear with Ren'Py Patch, and while a game has its own library. Runtimes offers Install and Import for an SDK version until Live2D is installed in it.
- Runtime archives compressed with Zstandard, such as vkd3d-proton 3.x, install without a separate `zstd` program.
- A runtime whose MacLauncher Builds versions are published under two package IDs, such as AnyPS5 and MacLauncher KosmicKrisp, lists all of them in one **MacLauncher Builds** menu.
