MacLauncher 0.6.3 imports shader options from existing presets, names the runtime version Play uses, and refines the library and inspector layout.

- A shader row's options end with **Import options…**, **Copy options** and **Paste options**. Import takes the matching values from a RetroArch `.slangp` or ReShade `.ini` preset, and Copy and Paste move a row's values as preset text between rows and presets. [Shader options](https://github.com/procrastinine/maclauncher/blob/v0.6.3/docs/graphics/EFFECT_PLANS.md#shader-options) describes the parsing and matching, including ReShade's compiled option names.
- The inspector's **Version** menu starts with **Automatic (vX)**, where vX is the version Play uses when the game has no version choice: a compatible installed version, otherwise the version Play installs. The lookup runs offline, and the entry reads **Automatic** until it answers. A saved choice that Play meets with an installed build, such as Godot 3.5.2 met by 3.5.2-stable, shows as that build.
- An exported Godot 3 game without C# always runs on the Standard build. Godot 3's .NET build stops at startup on such a game, which Play had used when only the .NET build of the game's version was installed. In the inspector, **.NET** is disabled for these games, with the reason under the **Variant** menu.
- Default game icons appear in the library of the packaged app; in 0.6.0 and 0.6.1 they stayed empty tiles. Game records store a default icon as a reference to its game type, so the icon follows the app when it moves or updates.
- Hosted web games, such as RPG Maker MV and MZ, run without an HTTP disk cache, which only held a second copy of the game's files. The cache folder that earlier versions left for a game is removed when the game next starts; saves and storage stay.
- Buttons for settings, folders, removal and closing are icons, and the runtime settings button sits beside the **Runtime** menu. The game list meets the inspector without a gap, the inspector header has its own separator, and in the stacked layout the scrollbars sit in the window's right margin.
- Dragging files onto the window covers it with the drop target and closes any open menu.
- **Settings**, **Runtimes**, **External** and **Credits** no longer repeat the window title as a heading. **External** opens on its tabs, with the Steam account controls at the top of the **Steam** tab and **Open downloads in Finder** in the **Downloaded** toolbar. Links in **Credits** open directly, and Settings buttons and shortcut names use sentence case. Inspector statuses take one line, with their explanation in help.
