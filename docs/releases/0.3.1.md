MacLauncher 0.3.1 adds more game backends and file tools.

- Play RPG Maker 2000/2003 games with EasyRPG, adventure games with ScummVM, WOLF RPG games with Browser Woditor, and FAVORITE/FVP games with RFVP.
- Use an installed CrossOver application for Windows games, with automatic discovery and per-game runtime settings.
- Explore Unity assets with AssetRipper, Flash files with JPEXS, and Infinity Engine files with Near Infinity. Export RPG Maker project data and KiriKiri scripts, and extract ScummVM, WOLF RPG and FVP resources.
- Improved runtime selection, save handling and tool shutdown. Missing runtimes and tools install after download consent; Python remains included.
