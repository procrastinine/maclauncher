MacLauncher 0.8.0 groups Wine builds by CPU, puts runtime defaults in the Installed section, and gathers the downloads needed for Play into one confirmation.

- Runtimes has separate Apple Silicon and Intel Wine entries, with a tab for each Wine source. Registered Wine builds show their release, folder and included components. Runtime defaults can be chosen directly from installed versions.
- A game appears in the library as soon as import begins. Play lists the required runtimes, tools and graphics data together, with their versions and download sizes.
- The game inspector shows the Direct3D and Vulkan choices compatible with the selected Wine. The Vulkan driver choice appears when a selected translator uses Vulkan or a driver preference is saved.
- MetalSharp Wine and Highball Wine are available alongside existing Wine sources. MacLauncher DXMT supports managed renderer packages and keeps its renderer selected when a game can run without optional NGX forwarding.
- Apex Neural Rendering provides scene frame generation. Compatible model kits can be downloaded or imported separately. The Runtimes window also manages FSR 4 model data, XeSS versions, and Lossless Scaling models obtained through Steam.
- Godot scene frame generation receives the interface as a separate layer, so the HUD can be composited at the output resolution. Game screenshots use the drawable even when graphics output skips a frame.
- FreeArc and SREP support compatible installers. Runtimes also manages Steam client files, Steamworks JNI libraries, mpv plugins, Android system images and the Android image reader.
