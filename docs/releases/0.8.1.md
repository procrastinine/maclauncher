MacLauncher 0.8.1 includes graphics package 0.3.14 and refines runtime selection, Settings and the Runtimes window.

- Runtimes shows when a runtime is loading. Installed rows are aligned, and the Neural models table gives model names, operations and defaults more room. The Default menu uses the width of its current choice. Runtime managers that choose among versions can offer **Make default** for included copies as well as separately installed versions.
- Settings lists game types by their display names and shows a shared section and runtime name once. Window graphics sessions appear as **Window capture** in the library and Settings.
- When vkd3d-proton needs a DXGI partner, selection honors a saved compatible DXVK default within the normal source order. AnyPS5 honors an explicitly selected Intel package when an Apple Silicon package has the same version. Existing version-only selections remain supported.
- Graphics package 0.3.14 includes the Apex Neural Rendering generation runtime. Compatible Apex model weights are installed separately. The package also includes Contrast Adaptive Sharpening and the Godot provider for composing the interface at the output resolution with MetalFX scene frame generation.
- The documentation and interactive website demo reflect the current Runtimes tabs, Windows translator choices, runtime defaults and Window capture controls.
