MacLauncher 0.5.2 includes graphics for other apps' windows and displays, Half-Life playback through Xash3D FWGS, frame generation built on macOS frameworks and Play from the original game folder.

- [Window graphics](https://github.com/procrastinine/maclauncher/blob/v0.5.2/docs/game-types/WINDOW.md) apply effects to another app's window or to a display. Each one chosen in **File → Apply Graphics…** gets its own library entry and graphics chain. The processed image stacks with the window, passes clicks through and can fill the screen or enlarge the window. Window graphics need macOS 15.2 or later.
- [Half-Life](https://github.com/procrastinine/maclauncher/blob/v0.5.2/docs/game-types/HALF_LIFE.md) and mods built on its game code run on Xash3D FWGS, a native engine that reads the original game data.
- VideoToolbox interpolation, MetalFX image interpolation and Vision optical flow [generate frames](https://github.com/procrastinine/maclauncher/blob/v0.5.2/docs/graphics/README.md#frame-generation) without model files. Graphics also gain a performance overlay, a frame-rate cap and shortcuts that bypass effects or save a processed screenshot. The **DLSS · 540p + LSFG 4×** preset becomes **DLSS · 720p + LSFG 4×**, and new DLSS rows start from a 720-pixel input height.
- Play runs games from their [original folders](https://github.com/procrastinine/maclauncher/blob/v0.5.2/docs/library/GAME_PREPARATION.md#original-game-paths) with the engine's own save locations, including Windows games in CrossOver and Sikarugir, Ren'Py, Godot, GameMaker, HashLink, GemRB, FNA and complete Ikemen GO distributions. On the first startup after upgrading, the library window shows progress while files from [earlier private game folders](https://github.com/procrastinine/maclauncher/blob/v0.5.2/docs/library/GAME_PREPARATION.md#earlier-private-game-folders), including the private home folder of 32-bit Mac games, are recovered once into the original folders, with differing files kept beside the originals.
- Import and Play preparation reuse earlier checks of unchanged runtime files and installer extractions. An [upkeep pass](https://github.com/procrastinine/maclauncher/blob/v0.5.2/docs/development/DATA_MODEL.md#derived-data-upkeep) once per start removes files left by earlier launches and downloads. It also removes a runtime version that Play installed only as a default, after a newer default is installed and while nothing uses it.
- External → Android reaches Google Play without starting Android. Android runtime 0.2.1 reuses the IDs of ended processes and threads before allocating higher ones.
- MacLauncher runs on macOS 13 or later, with separate downloads for Apple Silicon and Intel. Individual runtimes keep their own macOS requirements.
