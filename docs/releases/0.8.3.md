MacLauncher 0.8.3 runs a web game's own Electron app on separately installed Electron versions and recognizes more NW.js and Electron releases.

- **Runtimes → Electron** lists MacLauncher's own Electron and every stable Electron release, and installs a release only when its archive matches the SHA-256 that Electron publishes for it. Each web game type keeps one **Electron** runtime: MacLauncher's Electron hosts the game as before, and another version, chosen in the game's **Version** menu or as the default, runs the Electron app in the game's release with its own main-process script and preload scripts. A game without an Electron app of its own always uses MacLauncher's Electron. WOLF RPG Editor offers **Electron** for a release that holds an app.
- A game's own Electron app keeps its data where the game's own releases put it, starts without waiting for approval of downloaded native libraries, and reaches a running Steam client under network isolation when it carries Steam's macOS library.
- A Windows NW.js or Electron launcher counts as a web game launcher even when its version information no longer names NW.js or Electron, as long as Chromium's data files sit beside it and its app folder holds a real entry page.
- An Electron game's **About**, **Hide** and **Quit** menu items carry the game's name.
- GameMaker inspection reads audio-group tables that contain empty entries.
