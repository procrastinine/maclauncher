MacLauncher 0.4.0 includes versioned runtime downloads, Android execution and shared graphics controls.

- Select compatible MacLauncher Builds packages in Runtimes. Downloads and version changes are explicit; installed runtimes remain available offline.
- Import Android APK packages and select JVM, ART or AIM execution on Apple Silicon, with per-game storage, input and graphics settings.
- Configure ReShade, RetroArch and mpv shaders, upscaling and frame generation through shared graphics controls.
- Install the launcher from a single `MacLauncher.app.zip` for Apple Silicon and macOS 13 or later. Individual runtimes retain their own macOS requirements.
