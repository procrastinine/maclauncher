MacLauncher 0.6.0 adds a per-game choice of graphics translators for Windows games, the KosmicKrisp Vulkan driver, DLSS through MacLauncher's temporal upscalers, a Steam client bridge for Windows games and Switch 2 games.

- [Graphics translators](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/runtimes/TRANSLATORS.md) are chosen per game in CrossOver and Sikarugir: a default Direct3D engine, a translator for each Direct3D version from 8 to 12, a Vulkan driver and video codecs. Settings holds the defaults for all games. Versions installed in **Runtimes** are stored apart from CrossOver and the Sikarugir Templates, which are never modified. MacLauncher DXVK, an adapted DXVK 3.1.1 from MacLauncher Builds, is one of the DXVK choices.
- [KosmicKrisp](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/runtimes/KOSMICKRISP.md), the conformant Vulkan 1.4 driver for Apple Silicon from the Mesa project, is available next to MoltenVK for Vulkan games, the Vulkan-based Direct3D translators in Wine and ANGLE's Vulkan renderer for Android. MacLauncher KosmicKrisp adds the Vulkan features that DXVK, vkd3d-proton and ANGLE use. KosmicKrisp needs Metal 4 on Apple Silicon hardware, and MoltenVK serves Intel Macs, macOS versions before 26 and virtual machines.
- With the Vulkan driver on **Automatic**, a Windows game keeps its Wine runtime's own Vulkan driver. A game that uses MacLauncher DXVK or vkd3d-proton from **Runtimes** runs on MacLauncher KosmicKrisp.
- Games that use [DLSS](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/graphics/INPUTS_AND_ADAPTERS.md#dlss-through-vulkan-translators) have their Super Resolution evaluations run by MacLauncher's shared temporal upscalers through DXMT and D3DMetal, and through DXVK and vkd3d-proton on MacLauncher KosmicKrisp or a MoltenVK build with temporal-carrier support. No setting is involved.
- [Translator environment variables](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/runtimes/TRANSLATOR_ENVIRONMENT.md) have global values in **Settings → Environment variables** and per-game values, for Wine and its translators, the Android execution engines with ANGLE and the Vulkan driver, and the PlayStation 5 runtimes.
- The [Steam client bridge](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/runtimes/WINDOWS_STEAM.md) connects a Windows game's own Steam API to the Steam client for Mac in CrossOver and Sikarugir, so Steam itself answers account, ownership and ticket requests. Play offers it for a game that includes `steam_api.dll` or `steam_api64.dll` and whose app ID is recorded in a local Steam library or a completed MacLauncher Steam download.
- [Switch](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/game-types/SWITCH.md) adds decrypted Switch 2 dumps, shown as **Nintendo Switch 2** once preparation identifies a Switch 2 title. NUP containers and decrypted dumps play without `prod.keys`.
- Every runtime manager has its own tab in [Runtimes](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/runtimes/README.md#the-runtimes-window), including small packages that other runtimes load, and **Runtimes → Tools → Downloaded files** manages every other downloaded file. Archives are deleted after extraction. **Settings → Graphics** holds the shader library and the graphics presets.
- Play uses a compatible installed runtime before downloading another one. XNA games that FNA cannot run start in the Windows runtimes.
- The app includes graphics 0.3.8 and the current releases of its included helpers. [System requirements](https://github.com/procrastinine/maclauncher/blob/v0.6.0/docs/runtimes/SYSTEM_REQUIREMENTS.md) lists each included package with its version.
