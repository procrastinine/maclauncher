MacLauncher 0.5.0 includes a native graphics and effects layer, PS5, Switch and DOS execution, and runtimes delivered from MacLauncher Builds.

- Stack ReShade, RetroArch and mpv shaders, upscaling, neural restoration and frame generation in any order for every runtime. Effects run on Metal and change live during play; video export applies the same chain.
- Play unpacked PS5 games through AnyPS5 or Prosper, Switch containers through nxnative and DOS programs through DOSBox Staging.
- Download engines, tools and helpers from MacLauncher Builds or their upstream publishers when Play needs them. The app includes only the graphics core and internal helpers.
- Use the game's own runtime version or the runtime's default. Every runtime with versions has a default, and Play asks before downloading a missing one.
- Inspect, extract and decompile game data from each game's inspector, including static reports for native programs.
- Install the launcher from a single `MacLauncher.app.zip` for Apple Silicon and macOS 13 or later. Individual runtimes retain their own macOS requirements.
