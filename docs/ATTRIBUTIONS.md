# Attributions

MacLauncher thanks the authors and contributors of the projects below. Credits in the launcher combine module manifests with [shared project metadata](../src/modules/shared/acknowledgments.json); links open only when requested. Inclusion here covers dependencies, optional tools and source references. Runtime availability and compatibility are described in the [guide](README.md).

MacLauncher-owned code uses the [MIT License](../LICENSE). Each upstream project and derived runtime patch retains its own terms. Full copyright notices, exceptions and component licenses accompany the sources or runtime payloads; this page does not replace them. [.gitmodules](../.gitmodules) lists upstream source locations; Git submodule commits, module catalogs and native bundle manifests pin their exact revisions. See [runtime distribution](runtimes/RUNTIME_DISTRIBUTION.md) for payload verification and notice locations.

CI uses the [checkout](https://github.com/actions/checkout), [setup-node](https://github.com/actions/setup-node), [upload-artifact](https://github.com/actions/upload-artifact), [download-artifact](https://github.com/actions/download-artifact) and [pnpm setup](https://github.com/pnpm/action-setup) actions. [CI setup](CI.md) records their pinned workflow and artifact scope.

Archive and executable tools use [7-Zip](https://www.7-zip.org/) (LGPL/BSD components and unRAR restrictions), [Python](https://github.com/python/cpython), [python-build-standalone](https://github.com/astral-sh/python-build-standalone), [pefile](https://github.com/erocarrera/pefile) (MIT), [aplib](https://github.com/snemes/aplib) (GPL-3.0) and [corrupy](https://github.com/CensoredUsername/corrupy) (WTFPL). Offline installer imports use [innoextract](https://github.com/dscharrer/innoextract)

## Native adaptations and source references

[OpenBGI](https://github.com/Cytlan/openbgi) (GPL-2.0) is a BGI archive/program source reference; BGI is not yet supported for play. The [owned adapter source and decoder notice](../src/modules/mages/native) preserve its pins and patch license. Its decoder build uses LGPL configuration; other bundled video builds may have GPL components.

[ReMinori](https://github.com/luoyily/ReMinori) (AGPL-3.0) supplies the selected PAZ native interpreter. The [macOS adaptation](runtimes/MINORI.md) uses revision [`79b00990324404bfbd496e7fa76c690cf040f744`](https://github.com/luoyily/ReMinori/commit/79b00990324404bfbd496e7fa76c690cf040f744), owned platform/archive overlays and an [FFmpeg](https://ffmpeg.org/) 7.1.2 movie bridge built with LGPL-2.1-or-later configuration. Rust dependencies retain their own notices; the interpreter, movie libraries and corresponding source retain their respective license obligations.

[FelineSystem2](https://github.com/kokseen1/FelineSystem2) is a compatibility source reference. Its pinned core has no license and is excluded from distribution.

## Proprietary components

[Unity player components](https://unity.com/releases/editor/archive), [official GameMaker runtimes](https://gamemaker.io/) and [Adobe Flash Player](https://www.adobe.com/products/flashplayer/end-of-life.html) retain vendor terms. The included universal Flash Player 35.0.0.60 originated from [Adobe Animate](https://www.adobe.com/products/animate.html) and retains Adobe and its licensors' copyright notices. The Unity Mono route supports specific profiles, including development conversions with additional limits; it is not a general Windows Unity port. The public [GameMaker HTML5 source](https://github.com/YoYoGames/GameMaker-HTML5) is a vendor compatibility reference with its own copyright and terms; it is not covered by the launcher's license. Original game data, commercial engine exports and third-party assets remain their owners' property.

The included [offline Steam API](../src/modules/shared/runtime/steamworks/native/offline-0.5.0) and [encrypted-ticket loader](../src/modules/shared/runtime/steamworks/native/ticket-0.1.0) are independent MacLauncher implementations under MIT. Their complete source archives contain no SDK headers, SDK libraries or emulator source. Their finite API scope is described in [Steam support](runtimes/STEAM_API.md).

Valve's [Steamworks SDK](https://partner.steamgames.com/doc/sdk) has separate [SDK access terms](https://partner.steamgames.com/documentation/sdk_access_agreement). LuaSteam's developer header input is pinned to SDK 1.63 in the [source mirror](https://github.com/rlabrecque/SteamworksSDK); its source package records that input without including SDK headers or official SDK/ticket binaries. The legacy Goldberg developer source includes separately licensed SDK material and is excluded from the app's release payload. End users need no SDK or compiler for Automatic mode. Importing genuine libraries for Native mode does not change their license terms.
