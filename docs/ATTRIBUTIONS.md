# Attributions

MacLauncher thanks the authors and contributors of the projects below. The list covers dependencies, optional tools and projects used as source references. The **Credits** window in the launcher combines the acknowledgments in module manifests with the [shared project metadata](../src/modules/shared/acknowledgments.json), and its links open only when selected. The [guide](README.md) describes which runtimes are available and what they support.

Code written for MacLauncher uses the [MIT License](../LICENSE). Each upstream project, and each runtime patch derived from one, keeps its own terms. The full copyright notices, exceptions and component licenses ship with the sources or runtime packages, and this page does not replace them. [.gitmodules](../.gitmodules) lists the upstream source locations, and Git submodule commits, module catalogs and native bundle manifests record their exact revisions. [Runtime distribution](runtimes/RUNTIME_DISTRIBUTION.md) describes how packages are verified and where their notices are kept.

## Launcher and shared tools

### Store clients

Steam library access and game downloads use [node-steam-user](https://github.com/DoctorMcKay/node-steam-user) (MIT), [steam-session](https://github.com/DoctorMcKay/node-steam-session) (MIT), [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT), [node-steam-crypto](https://github.com/DoctorMcKay/node-steam-crypto) (MIT) and their packaged dependencies. Steam content stays subject to the account's licenses and the publisher's access rules.

Epic downloads acquire [Legendary](https://github.com/derrod/legendary) (GPL-3.0), and GOG Galaxy downloads acquire [GOGdl](https://github.com/Heroic-Games-Launcher/heroic-gogdl) (GPL-3.0), only when requested. Their upstream source, license and exact download records are kept with the tools. The GOG offline-download API mappings follow [gog-cli](https://github.com/aleksandarristic/gog-cli), and itch.io uses the [official consumer API](https://github.com/itchio/go-itchio).

### Graphics

MacLauncher's optional per-game effects use the [ReShade](https://github.com/crosire/reshade) FX compiler (BSD-3-Clause), [SPIRV-Cross](https://github.com/KhronosGroup/SPIRV-Cross) (Apache-2.0 or MIT), [SPIRV-Headers](https://github.com/KhronosGroup/SPIRV-Headers) (MIT) and the [CC0 ReShade shader headers](https://github.com/crosire/reshade-shaders). The macOS adapter source is BSD-3-Clause. The combined native compiler and graphics component also contain [MAKO](https://github.com/eugeniosegala/MAKO) model inspection and processing code under GPL-3.0-or-later, and the corresponding source and notices ship with those components.

Proprietary Lossless Scaling model files are imported from a purchased copy and are not included. The optional download of those files uses Valve's proprietary [SteamCMD](https://developer.valvesoftware.com/wiki/SteamCMD), which is downloaded only on request and is not included either.

The CRT, Grayscale, Colour and Sharpen presets are MacLauncher's own MIT code. The additional included collection uses [SweetFX](https://github.com/CeeJayDK/SweetFX) effects and SMAA lookup textures under MIT, SweetFX's FXAA with NVIDIA's original FXAA 3.11 notice, and [RSRetroArch](https://github.com/Matsilagi/RSRetroArch) CRT ports under their individual GPL and public-domain terms. Their source files and [complete notices](../src/modules/shared/reshade/shader-collection/NOTICE.md) ship with the collection. [CRT Royale for ReShade](https://github.com/akgunter/crt-royale-reshade) contains Alex Gunter's port of TroggleMonkey's shader under GPL-2.0-or-later, with reusable includes under their embedded MIT terms, and its original sources, documentation and licenses ship with the collection. Custom shader files keep their own terms.

RetroArch Slang presets use [librashader](https://github.com/SnowflakePowered/librashader) (MPL-2.0). mpv shaders use [libplacebo](https://code.videolan.org/videolan/libplacebo) (LGPL-2.1-or-later), [shaderc](https://github.com/google/shaderc) (Apache-2.0), [Little CMS](https://www.littlecms.com/) (MIT) and [MoltenVK](https://github.com/KhronosGroup/MoltenVK) (Apache-2.0), whose notices ship with the graphics component.

Shader compilation also uses [glslang](https://github.com/KhronosGroup/glslang) (BSD-3-Clause, MIT and Apache-2.0 component terms) and [SPIRV-Tools](https://github.com/KhronosGroup/SPIRV-Tools) (Apache-2.0). ISF shaders use [ISFMSLKit](https://github.com/mrRay/ISFMSLKit) (MIT with component notices), its [glslang fork](https://github.com/mrRay/glslang) (BSD-3-Clause, MIT and Apache-2.0 component terms) and [SPIRV-Cross fork](https://github.com/mrRay/SPIRV-Cross) (Apache-2.0 or MIT), [VVMetalKit](https://github.com/mrRay/VVMetalKit) (MIT and Apple sample-code terms), [ISFGLSLGenerator](https://github.com/mrRay/ISFGLSLGenerator) (BSD-3-Clause), [PINCache](https://github.com/mrRay/PINCache) and [PINOperation](https://github.com/pinterest/PINOperation) (Apache-2.0).

FSR1 scaling uses the EASU and RCAS shaders of [AMD FidelityFX FSR](https://github.com/GPUOpen-Effects/FidelityFX-FSR) under MIT, and the original notice ships with the graphics component. The [FSR2](https://github.com/GPUOpen-Effects/FidelityFX-FSR2) and [FSR3 upscaler](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK) implementations are MIT. The [FSR4 Metal provider](https://github.com/UzenUPoZiTiV4ik/fsr4-native-macos) and its [shader implementation](https://github.com/int3rrobang/fsr4-int8-reverse-engineering) keep their MIT notices, together with the AMD model and helper notices that come with them.

The [FSR4 Lite 2 trained weights](https://github.com/zgauthier2000/fsr4-shader-performance-overrides) retain their separate GPL-2.0-or-later notice.

Native image filters adapt [Halide Local Laplacian](https://github.com/halide/Halide), [Intel XeGTAO](https://github.com/GameTechDev/XeGTAO) and [FXShaders](https://github.com/luluco250/FXShaders) under MIT. [Intel CMAA2](https://github.com/GameTechDev/CMAA2) uses Apache-2.0 and retains its MIT third-party notices.

Neural processing uses [MLX-DLSS](https://github.com/iamwavecut/MLX-DLSS) (Apache-2.0), [MLX](https://github.com/ml-explore/mlx), [MLX Swift](https://github.com/ml-explore/mlx-swift) and [MLX C API bindings](https://github.com/ml-explore/mlx-c) (MIT). [Swift Argument Parser](https://github.com/apple/swift-argument-parser) and [Swift Numerics](https://github.com/apple/swift-numerics) retain Apache-2.0 with the Swift runtime library exception.

Restoration architectures and ports include [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) and its [MLX architecture port](https://github.com/xocialize/realesrgan-mlx) (BSD-3-Clause), [SRVGG Swift](https://github.com/xocialize/mlx-realesrgan-swift), [Real-CUGAN](https://github.com/bilibili/ailab), [NAFNet](https://github.com/megvii-research/NAFNet), its [Swift port](https://github.com/xocialize/mlx-nafnet-swift) and [MLX architecture port](https://github.com/xocialize/nafnet-mlx) (MIT). Interpolation uses [RIFE](https://github.com/hzwer/Practical-RIFE) and [RIFE ncnn](https://github.com/nihui/rife-ncnn-vulkan) (MIT), with [ncnn](https://github.com/Tencent/ncnn) (BSD-3-Clause). Depth estimation adapts the [Depth Anything V2 Small architecture](https://github.com/DepthAnything/Depth-Anything-V2), its [DINOv2 architecture](https://github.com/facebookresearch/dinov2) and the [Transformers checkpoint layout](https://github.com/huggingface/transformers) under Apache-2.0. Source adaptations and model files retain their individual notices.

Automatic Metal depth-store preservation, multisample OpenGL copy orientation, captured-window frame geometry (which reads the content rectangle and scale metadata of ScreenCaptureKit frames), the reuse of Metal textures imported from captured IOSurfaces and the 16-bit BT.2020 PQ encoding of HDR screenshots adapt techniques from [MacShade](https://github.com/klotzbrocken/MacShade) (BSD-3-Clause); its notice ships with the graphics component. Vision optical-flow frame generation is ported from [MetalDuck](https://github.com/Nycolazs/MetalDuck) (MIT), and its notice ships with the graphics component. The Keep static content option, Automatic frame generation, display-limited generation and the measured processing sizes of image-pair generation follow techniques that [MetalGoose](https://github.com/Stallion77RepoOfficial/MetalGoose) (GPL-3.0) uses; MacLauncher's implementations contain none of its code.

## Backends and module tools

Most runtimes and tools in this section are downloaded separately through **Runtimes**; [Runtime distribution](runtimes/RUNTIME_DISTRIBUTION.md) lists the components included in the app.

DOS playback uses the publisher's [DOSBox Staging](https://github.com/dosbox-staging/dosbox-staging) applications, downloaded separately, under GPL-2.0-or-later, with the component notices that the project supplies. DOS program inspection uses the shared Rizin and Ghidra tools and their notices.

Half-Life playback uses the publisher's [Xash3D FWGS](https://github.com/FWGS/xash3d-fwgs) builds, downloaded separately, under GPL-3.0-or-later. Each build includes SDL2 under zlib and the Half-Life game libraries built from [hlsdk-portable](https://github.com/FWGS/hlsdk-portable), the FWGS port of Valve's Half-Life SDK, under the Half-Life 1 SDK License. Half-Life's game data comes from the imported game.

The Android host adapts [Klepton](https://github.com/shinyquagsire23/Klepton) (MIT) and [dex2jvm](https://github.com/kksimp/dex2jvm) (Apache-2.0). It signs with [Android apksig](https://android.googlesource.com/platform/tools/apksig/) (Apache-2.0), uses [SDL3](https://github.com/libsdl-org/SDL) (zlib) for windows and input, and uses [ANGLE](https://chromium.googlesource.com/angle/angle) (BSD-3-Clause) for OpenGL ES rendering. Their component notices ship with the runtime. The converter uses API hierarchy metadata during conversion, which is not an implementation of the Android framework.

The ART runtime is built from the [Android Runtime](https://android.googlesource.com/platform/art) (Apache-2.0).

The other Android runtimes are [Mac.apk](https://github.com/kksimp/Mac.apk) publisher releases (AGPL-3.0 or a separate commercial license) and an adapted [AIM](https://github.com/hahnlee/aim) host (Apache-2.0). Upstream copyright and component notices ship with the selected runtime. AIM's separately acquired Android image keeps its publisher's terms and is not part of MacLauncher distributions.

## Native adaptations and source references

[OpenBGI](https://github.com/Cytlan/openbgi) (GPL-2.0) is a source reference for BGI archives and programs. BGI has no native interpreter, and compatible Windows builds can use Sikarugir or CrossOver. The Mac [OpenGMK](https://github.com/OpenGMK/OpenGMK) runner uses [ramen](https://github.com/viriuwu/ramen) (Zlib) and [udon / libsoundio-sys](https://github.com/Adamcake/udon), and the Classic interpreter and decompiler are versioned separately.

The Windows [Impacto](https://github.com/CommitteeOfZero/impacto) adaptation (ISC) runs the Windows HD data profile. It uses [FFmpeg](https://ffmpeg.org/) 7.1.2 with the [sharpemu/ffmpeg-core Bink2 patch](https://github.com/sharpemu/ffmpeg-core) (LGPL-2.1-or-later; decoder authors Konstantin Shishkov and Paul B Mahol), [avcpp](https://github.com/h4tr3d/avcpp), [LibAtrac9](https://github.com/Thealexbarney/LibAtrac9), [magic_enum](https://github.com/Neargye/magic_enum), [GLM](https://github.com/g-truc/glm), [Boost](https://www.boost.org/), [pugixml](https://github.com/zeux/pugixml), [unordered_dense](https://github.com/martinus/unordered_dense), [readerwriterqueue](https://github.com/cameron314/readerwriterqueue), [concurrentqueue](https://github.com/cameron314/concurrentqueue), [utf8cpp](https://github.com/nemtrif/utfcpp) and [toml11](https://github.com/ToruNiina/toml11). The corresponding build sources include [Catch2](https://github.com/catchorg/Catch2), avcpp's BSL-1.0 test dependency. The [adapter source and decoder notice](../src/modules/mages/native) record its exact versions and the patch license. Its decoder is built with an LGPL configuration, while other bundled video builds can contain GPL components.

[ReMinori](https://github.com/luoyily/ReMinori) (AGPL-3.0) supplies the native interpreter for the selected PAZ profile. The [macOS adaptation](game-types/MINORI.md) uses revision [`79b00990324404bfbd496e7fa76c690cf040f744`](https://github.com/luoyily/ReMinori/commit/79b00990324404bfbd496e7fa76c690cf040f744), MacLauncher's platform and archive changes, and an [FFmpeg](https://ffmpeg.org/) 7.1.2 movie bridge built with an LGPL-2.1-or-later configuration. Rust dependencies keep their own notices, and the interpreter, movie libraries and corresponding source keep their license obligations.

[FelineSystem2](https://github.com/kokseen1/FelineSystem2) is a compatibility source reference. It is not distributed or run, because it does not play CatSystem2 games.

The included [offline Steam API](https://github.com/procrastinine/maclauncher-builds/blob/main/producers/package-support/src/modules/shared/runtime/steamworks/native/offline-0.5.0/source/offline.cpp) and [encrypted-ticket loader](https://github.com/procrastinine/maclauncher-builds/blob/main/producers/package-support/src/modules/shared/runtime/steamworks/native/ticket-0.1.0/source/ticket.cpp) are independent MacLauncher implementations under MIT. Valve's [Steamworks SDK](https://partner.steamgames.com/doc/sdk) has separate [SDK access terms](https://partner.steamgames.com/documentation/sdk_access_agreement). Players need no SDK or compiler for **Automatic** mode, and importing genuine libraries for **Native** mode does not change their license terms.
