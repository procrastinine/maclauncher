# PlayStation 5 / AnyPS5

MacLauncher identifies unpacked PS5 games from their `sce_sys/param.json` metadata and PS5 ELF or SELF executable. The folder or its `eboot.elf`, `eboot.bin` or `eboot.self` can be imported directly. Ordinary Linux ELF and macOS executables do not match this format. PS5 PKG archives retain offline package inspection; Play and decompilation require unpacked, decrypted input.

Prepared AnyPS5 folders with original executables and modules in `source/` and assets in `app0/` are also recognized. Metadata-backed folders identify programs by ELF or SELF headers, including files with other names or extensions. Mac preparation converts the original PS5 programs and nested modules; existing converted outputs remain separate from those inputs.

[AnyPS5](https://github.com/boykopovar/AnyPS5) versions are managed through MacLauncher Builds. **Refresh** queries the runtime version catalog; installed versions remain available offline. Play requests consent for missing runtimes, installs the selected package and resumes preparation. No Python installation or source checkout is required.

The runtime converts the x86-64 PS5 executable and bundled modules into Mach-O files. On Apple Silicon, the converter runs natively and the converted program uses Rosetta. Required Rosetta installation follows the system consent flow. PS5 system interfaces use the selected AnyPS5 package's libraries. The macOS runtime requires macOS 26 or later.

**Vulkan** selects an installed implementation with Intel support. Automatic selection prefers compatible KosmicKrisp and requests a managed download when needed. ARM-only Vulkan libraries cannot load in the Rosetta game process. Settings → PlayStation 5 → PS5 (AnyPS5) sets the default for all games, and each game's runtime settings can override it. The choice lists installed implementations without a network request.

Preparation copies game resources into the game's private launcher data and preserves the original `eboot.bin`. Conversion is cached by the game input and runtime version. Private resource edits and saves survive conversion updates. Save-location settings redirect `/data` and the `_sd` save-data tree into the selected save folder; other runtime files remain in the game's launcher data.

Runtime settings include editable keyboard, mouse and wheel bindings. The face buttons form a keyboard diamond: I is Triangle, J is Square, K is Cross and L is Circle. Space and Return also press Cross; C also presses Circle. Q/E are L1/R1, R/U are L2/R2, Shift is L3, Ctrl is R3 and Escape is Options. WASD moves the left stick, T/G/F/H moves the right stick, and the arrow keys operate the D-pad. Backspace and Tab touch the left and right touchpad zones; V clicks the touchpad on runtimes with touchpad key support. Left click also presses R2 and right click presses Square. Other bindings remain visible in the same settings window. Each game inherits the module defaults and can override them or reset to those defaults.

Mouse input can use controller bindings or the game's native mouse API. These routes are exclusive, so a click does not trigger both inputs. Controller bindings map buttons and wheel events to the pad; captured motion controls the right stick. Native mouse sends movement, buttons and wheel events to the game's mouse API. Automatic preserves the selected runtime's default; runtimes with routing support use controller bindings on macOS even when a game opens the native mouse API. Explicit mouse input selection requires that runtime capability.

The pointer starts visible and uncaptured. F7 or middle click toggles capture for the selected route. Configured capture buttons are reserved for that host action; native mouse games receive the middle button when it is removed from the capture binding. Releasing capture restores the pointer, and an explicit release persists across focus changes. Bindings and routing apply on the next launch.

Binding fields accept comma-separated key names such as `Return, Space`, mouse names such as `Mouse Left`, and wheel directions such as `Wheel Up`. `Comma` names the comma key. Blank fields restore their defaults; the optional stick modifier is unbound by default. Mappings use AnyPS5's existing input configuration and apply on the next launch. Physical controller input remains available.

**Inspect program** exports metadata and the import registry when a conversion exists. **Decompile** uses the shared managed Rizin/Ghidra tools to export ELF metadata, imports, symbols, strings, functions and C pseudocode. SELF extraction uses the selected AnyPS5 package. **Show export** reveals the latest inspection output. Pseudocode does not reconstruct an original source project.

**Inspect package** reads bounded FIH, CNT and PFS headers without a runtime download or package extraction. It reports signing, filesystem encryption when established by a readable superblock, and available container metadata. Title IDs inferred from filenames retain that source label. Missing CNT metadata is reported without treating every metadata-free package as corrupt. Encrypted packages expose an inspection reason and cannot enter conversion or decompilation.
